# 1.0.0 · A hello within reach

First Wear OS companion release: recent chats and unread counts, message threads, keyboard/dictated replies, editable quick replies, reactions, mark read, mute, open-on-phone requests and an encrypted outbox/cache.

Explicit approval happens on the phone. Watch requests are account-scoped; stable transaction IDs prevent duplicate replies after retry. Passwords, access tokens and Matrix message keys stay on the phone.

First-release preview pending paired physical-device testing. Requires the matching Android phone app, Google Play services and a connection to the phone for new messages and sending. No independent Matrix login, calls or watch media streaming.
